# Jungle Math Adventure

Struktur awal proyek game edukasi perkalian dan pembagian untuk kelas 4–6 SD.

## Struktur Utama
- `index.html` : halaman utama game.
- `css/` : seluruh gaya tampilan dan responsive.
- `js/` : seluruh logika permainan.
- `data/` : level, soal, karakter, dan prestasi.
- `assets/` : gambar dan audio.

## Wilayah
1. Hutan Bambu
2. Sungai Angka
3. Gua Kristal
4. Rawa Misteri
5. Hutan Kabut
6. Gunung Penjaga

## Catatan
Folder aset masih memakai file `.gitkeep` sebagai placeholder.
Aset gambar dan audio dapat dimasukkan kemudian tanpa mengubah struktur utama.
